# Ayrılan görseller

Bu klasördeki 7 Man8 saç PNG'si oyuncu asset kataloğunda, kayıtlı poz dosyalarında veya mevcut portre üretim kodunda kullanılmıyor. Hiçbir dosya silinmedi. Orijinal PNG/Hair/... klasör yapısı korundu.

Diğer renk varyantları hâlâ portre ve karakter düzenleyici tarafından kullanılıyor. Yalnızca aynı renklendirilebilir şekle benzediği için taşınmadılar.

Geri almak için dosyaları aynı göreli yollarla proje köküne taşıyabilirsiniz. tasınan-dosyalar.json dosya listesini içerir.
