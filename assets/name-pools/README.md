Country name data includes female/generic given names and family names from https://github.com/faker-js/faker/tree/main/src/locales (retrieved 2026-10-23). Original game pools remain included. Supplemental Japanese and Thai names and culturally used compound given/family names extend smaller pools. All countries provide at least 118,295 distinct given/family combinations; values follow the existing 24-character save limits.

Japanese pools use Latin Hepburn spelling. Legacy generated Japanese names have a lookup table so saved players keep the same identity when converted.
