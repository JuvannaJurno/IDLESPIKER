# Portre küpeleri

İki şeffaf PNG; her görselde bir sağ-sol çift vardır. Orijinal üretimler değiştirilmeden saklandı.

- gold-studs.png: Altın top küpe
- gold-short-drops.png: Kısa altın damla

preview.html mevcut oyun portresinde küçük ölçekte görünüşü gösterir. manifest.json ayrı sağ/sol kaynak dikdörtgenlerini, önerilen ölçekleri ve portre bağlantı noktalarını içerir. Altın top ve kısa altın damla modelleri oyun portrelerinde kullanılır.

Üretim: built-in image_gen. Kullanılan tam promptlar generation-prompts.json dosyasında. Kısa prompt özeti: Kenney tarzında önden portrelere uygun, küçük, iki tonlu sağ-sol küpe çiftleri; şeffaf zemin, doku veya gerçekçi parlama yok.
